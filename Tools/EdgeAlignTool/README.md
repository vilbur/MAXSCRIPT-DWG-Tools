# EdgeAlignTool

Tool for aligning selected objects by picked source and target edges.

## Entry script

- [`EdgeAlignTool.ms`](EdgeAlignTool.ms)

## Macro

- `_DwgTools_EdgeAlignTool`

## Overview

- Uses picked edges to align one object or group to another.
- Supports 2D edge-alignment workflows.
- Includes controls intended for edge, hinge, or fold-style alignment tasks.
