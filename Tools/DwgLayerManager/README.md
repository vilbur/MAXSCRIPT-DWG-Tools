# DwgLayerManager

Layer-management tool for imported DWG data in 3ds Max.

## Entry script

- [`DwgLayerManager.ms`](DwgLayerManager.ms)

## Macro

- `_DwgTools_DwgLayerManager`

## Overview

- Opens a layer-management UI for DWG-imported layers.
- Loads helper modules for layer export, layer cleanup, keyword management, tree generation, and layer toggle callbacks.
- Useful after DWG import and trimming, when imported layers need cleanup or review.
